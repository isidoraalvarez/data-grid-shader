# DATA_GRID // Video Shader Studio

Estudio web interactivo de procesamiento de video en tiempo real con estética cyber-brutalista. Desarrollado con Three.js y Tailwind CSS.

## Características
- Procesamiento 3D y extrusión volumétrica por luminancia.
- Modos de renderizado: Point Cloud, Matrix Code (0136) y Wireframe.
- Soporte para navegación orbital con trackpad y exportación a .webm.
